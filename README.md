# Portafolio de Juan Esteban Velásquez Perdomo

Sitio estático en español para GitHub Pages, con fotografía personal, proyectos de Electrónica Análoga 3 y portafolio PDF.

## Publicación

Subir el contenido de esta carpeta a la raíz del repositorio. En Settings → Pages, seleccionar Deploy from a branch, rama main y carpeta / (root). Guardar y esperar la publicación. No requiere Node, dependencias ni compilación.

## Contenido

- `index.html`: perfil, proyectos, proceso y aporte individual.
- `styles.css`: diseño adaptable y estilos accesibles.
- `assets/juan-esteban.jpeg`: fotografía proporcionada por el autor.
- `documentos/portafolio.pdf`: documento de respaldo.

Las cifras provienen de los informes del curso. Los resultados de equipo, la participación individual declarada y las verificaciones pendientes se distinguen en el contenido. La cotización no es un precio actualizado.
